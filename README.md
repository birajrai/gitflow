# GitFlow

A cross-platform desktop git workflow assistant. Pick a git repository, watch its
file changes live, and stage, commit, and push from a natural-language chat
interface. Commit messages are generated by an AI model through the NVIDIA NIM
API (OpenAI-compatible, free tier). Built with Tauri, Svelte, and Rust.

## Features

- Live file status panel (`git status`), refreshed every 5 seconds while focused
- Chat-driven git actions: `commit`, `commit and push`, `push`, `what changed?`,
  `undo last commit`, `diff`, `commit this as <message>`
- Editable AI commit-message confirmation card with conventional-commits style
  generation via NVIDIA NIM
- Quick action pills (Commit / Push / Commit & Push)
- Settings panel: NIM API key, model, connection test — persisted locally
- System-aware theming (light/dark via `prefers-color-scheme`)

## Prerequisites

Follow the official Tauri prerequisites for your OS:
https://tauri.app/start/prerequisites/

- **Linux**: WebKitGTK 4.1, GTK3, and build tools (see the distro-specific list
  on the prerequisites page)
- **Windows**: Microsoft C++ Build Tools (Desktop development with C++) and
  WebView2 (ships with Windows 10 1803+ / Windows 11)
- **macOS**: Xcode (or Command Line Tools for desktop-only development)

You also need:

- [Rust](https://rustup.rs) (stable)
- [Node.js](https://nodejs.org) LTS
- [Bun](https://bun.sh) package manager
- `git` on PATH

## Getting a free NVIDIA NIM API key

1. Go to https://build.nvidia.com
2. Sign in (an NVIDIA account is enough — no credit card required)
3. Pick any model (e.g. `meta/llama-3.3-70b-instruct`), open the API section,
   and copy your API key (`nvapi-...`)
4. Paste it into GitFlow: **Settings (gear icon) → NIM API key**

## Development

```sh
bun install
bun run tauri dev
```

## Releasing

Push a version tag. The GitHub Actions workflow builds and uploads
`.AppImage` / `.deb` (Linux), `.msi` (Windows), and `.dmg` (macOS) to a draft
release.

```sh
git tag v1.0.0
git push origin v1.0.0
```

## GitHub Actions secrets

Set these in the repository settings (Settings → Secrets and variables →
Actions):

| Secret | Purpose |
| --- | --- |
| `TAURI_SIGNING_PRIVATE_KEY` | Tauri private signing key (base64) for bundle signing |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | Password protecting the signing key |

Generate a signing key with:

```sh
bun run tauri signer generate -w ~/.tauri/gitflow.key
```

If the secrets are not set, builds still succeed but bundles are unsigned.

## Notes

- `config.json` and `.env` are gitignored — never commit credentials.
- Settings (API key, model, last repo) are stored locally by `tauri-plugin-store`.
